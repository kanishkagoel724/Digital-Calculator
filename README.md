# Digital-Calculator

A clean, modern, and responsive **Digital Calculator** built with **HTML, CSS, and JavaScript**. The project features a soft lavender-themed interface with an intuitive layout and interactive calculator functionality.

## ✨ Features
* 🧮 Basic arithmetic operations
* 🔢 Decimal and percentage calculations
* ➕ Addition, subtraction, multiplication, and division
* 🧹 Clear and reset functionality
* ⌫ Delete/backspace functionality
* 📱 Responsive and user-friendly interface
* 💜 Modern lavender-themed UI
* ⚡ Fast and interactive calculations using JavaScript

## 🛠️ Technologies Used
* **HTML5** – Structure of the calculator
* **CSS3** – Styling, layout, responsiveness, and visual design
* **JavaScript** – Calculator logic and interactive functionality

## 🎨 Design
The calculator uses a **minimal lavender aesthetic** with a clean layout, rounded elements, and an easy-to-use interface. The design focuses on simplicity while maintaining a modern and visually appealing look.

## 🚀 How to Run
1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in any modern web browser.
4. Start calculating! 🧮✨
